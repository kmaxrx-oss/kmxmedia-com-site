---

## Product law

**Sell in this order:**

1. Fix visible damage (painkiller)
2. Make the business findable (SEO + structured facts)
3. Improve the customer path (calls, orders, booking, contact)
4. Offer ongoing care only after trust exists

**Never lead with:** rebuilds, hosting migration, AI buzzwords, OpenTable/Resy, monthly plans, or a long service menu.

**Always attach to outcomes:** calls, bookings, foot traffic, orders, search visibility, specials, repeat visits, less website hassle.

## Tier 1 — Painkiller repairs

### 1. Website Critical Fix — **$250 flat** (range $150–$350 by severity)

- HTTP/HTTPS redirect repair
- WordPress critical error / white screen triage
- Plugin/theme conflict check
- Mobile + desktop smoke test
- Contact / menu / order-link check
- Short “what was wrong / what changed” summary

**Say:** repair call, not audit. Not a rebuild. Not a contract.

### 2. Website Safety + Access Cleanup — **$150–$300**

- Admin access cleanup
- Backup plugin check
- Update risk check
- Remove abandoned admin users (if authorized)
- SSL/plugin health check
- Document where hosting/DNS lives

**Best for:** old WordPress sites nobody owns anymore.

---

## Tier 2 — Findability

### 3. Local SEO Foundation — **$450–$650**

- Title/meta and heading cleanup
- Local service/location language
- Internal links to key action pages
- Google Business Profile consistency notes
- Local business schema (where appropriate)
- Image alt basics
- Crawl/indexing sanity check

**Say:** “Make Google understand the business.”

### 4. AI / Local Answer Readiness — **bundle, not standalone first**

**Standalone:** $200–$350 · **Better as bundle with SEO:** $550–$850

- Structured business facts / FAQ content
- `llms.txt` where appropriate
- Clean hours, location, services, booking rules
- Schema alignment

**Say:** “Structured facts so Google and AI assistants answer questions accurately.”  
**Do not say:** “AI optimization.”

---

## Tier 3 — Revenue / operations (add-ons)

### 5. Constrained booking / request flow — **$400–$750**

Scope to **business rules**, not generic “reservations”:

- Party minimums, hours, closed days
- Capacity or time-slot limits (if needed)
- Confirmation + staff notification
- Integration with existing popup/menu/contact
- Walk-in / phone-only messaging where policy requires it

**Method order:** existing platform first (e.g. Square) → simple WP form → booking plugin → marketplace (OpenTable/Resy) only if asked.

### 6. Specials / events email — **$300–$500 setup** · **+$49/mo** optional

- Signup form (footer, popup, or embedded)
- ESP setup (Mailchimp, Brevo, etc.)
- One reusable specials template
- Monthly send support (client provides content)

**Say:** “simple specials email,” not marketing automation.

### 7. Customer path cleanup — **$200–$400**

- Primary CTAs obvious on homepage
- Order / menu / contact / booking paths clarified
- Competing buttons reduced
- Mobile customer-flow check
- External tools linked clearly (Square, etc.)

**Generalizes to:** restaurants, salons, contractors, venues — whatever their “main action” is.

## Sales motion (per lead)

1. **Diagnose** one visible problem (free/low-cost first look)
2. **Offer Package A** only
3. **After fix or trust:** recommend B or C based on need — not both at once
4. **Add-ons** only when they map to stated pain (booking, email, path)
5. **Ongoing care** last

---

## Invariants (technical)

- HTTPS canonical domain before growth work
- No public URL should hit a WordPress critical error
- Piggyback existing stack (WordPress, Square, phone, popup) — improve, don’t replace
- Server/domain/WordPress truth consistent before SEO, booking, or AI layers

---

## What to avoid

- Rebuild pitch without evidence
- Standalone “AI agency” language
- OpenTable/Resy for businesses that reject small-party booking
- Hosting as first ask
- More than 3 packages in first conversation
- Guaranteed rankings or fake proof
